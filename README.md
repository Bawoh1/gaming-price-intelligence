# Gaming Price Intelligence Platform

An automated data engineering pipeline that tracks video game prices 
over time, stores historical data in PostgreSQL, and surfaces insights 
through Power BI dashboards.

## What This Project Does

- Fetches real-time game prices from the CheapShark API
- Stores and tracks price history in a PostgreSQL database
- Runs automated ETL pipelines to clean and transform data
- Displays trends, discounts, and store comparisons in Power BI

## Tech Stack

Python · PostgreSQL · SQL · Power BI · Git
